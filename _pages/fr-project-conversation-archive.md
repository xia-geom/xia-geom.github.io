Conversation Archive permet d’organiser les informations issues d’exports de conversations avec des assistants d’IA dans un document Markdown unique. Les références aux sources, les nuances et les corrections sont conservées avec les informations extraites.

Le travail associe des vérifications automatiques à une relecture humaine des ambiguïtés importantes. Les exports originaux sont préservés.

## Code source

[Consulter le dépôt sur GitHub](https://github.com/xia-geom/conversation-archive)

Le dépôt public contient le code, la documentation et un exemple d’utilisation fondé sur des données fictives. Le logiciel reste expérimental.
