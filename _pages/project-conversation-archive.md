## Keep the information, and keep where it came from

Useful information often accumulates across many AI conversations. A summary
alone can lose its sources, merge distinct events or make an uncertain connection
look settled. **Conversation Archive** explores a more traceable approach to
extracting and organizing that material.

The workflow preserves original exports, links candidate records to source
passages, and separates proposed connections from confirmed ones. Contextual
question batches support human review; recorded corrections can be reused rather
than rediscovered on every pass. Related records need not be collapsed into one.

## What the project is — and is not

This is an **experimental alpha**, not a fully autonomous knowledge system.
Source preservation, bounded candidate extraction, checked reconciliation and
relationship-review workflows are implemented in the repository. Semantic
connections still need review, and an exact quotation establishes provenance,
not necessarily a correct interpretation.

The source repository is currently private. This public page contains only a
project description and a demonstration using invented examples, not personal
conversation exports, extracted records or review answers. Optional model-assisted
extraction is not the same as an entirely offline workflow.
